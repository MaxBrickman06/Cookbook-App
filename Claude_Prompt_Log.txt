Examples from other groups:

VibePaint is an interactive game where you paint and AI critiques your work and builds it into the world. The critique includes a letter grade and a written response. These responses can be viewed again in the museum. You can use a Claude or Gemini API key and it will generate a 3d version of your 2d painting which is then added to the world. For example if you paint a tree a 3d rendition of that tree is added to the world. When it is added a beacon appears so you can see where the new model is located. The critiques also exist in the world, they walk around the art museum and you can talk with them. They will make comments on the paintings that you have made. When you first spawn into the game it will be dark and empty, you get a questbook that tells you what to paint to fill the world, for example the sun, flowers, and trees. There are villagers that will talk to you about their requests and will comment once you finish them. 

Offline mode is also available so the game is playable without an API key. Paintings are graded based on color theory, techniques, and composition so a critique is still generated. The 3D modeling in offline mode the game will ask you to select from options on what your painting is of. This determines where the item will spawn in like the sky, the lake, the grass etc. It then takes the painting and adds plain gray depth to it. If you want a proper 3d generated later there is a button at the painting in the museum to do so.

Limits:
• We ran across both human and LLM limits.
• Both: One big limit was tokens, especially with the free tier of Gemini API keys. This is both a human and LLM limit as money is a limiting factor for both.
• LLM limit: The bigger the project got the longer it took for the LLM to make changes and if its changes were bugged it took even longer.
• Human limit: As the project continued to get bigger it became almost impossible to debug anything by hand and therefore had to be left to the LLM which, as stated earlier, took more and more time to use
