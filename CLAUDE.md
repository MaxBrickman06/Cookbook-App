# Notes for Claude

## Prompt log (standing instruction from the project owner)
Every prompt the user gives for this project must be added to `Claude_Prompt_Log.txt` in the repo root,
word for word, with its date and time (US Eastern, e.g. `[2026-10-15 11:15 EDT]`) and the branch being
worked on. Add the newest prompt at the bottom, in the same format as the existing entries, and commit
the update together with the work for that prompt (or on its own if the prompt needs no code changes).
